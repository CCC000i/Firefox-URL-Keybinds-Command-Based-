Mozilla-legal version of URL Keybinds (https://github.com/CCC000i/Firefox-URL-Keybinds), not signed yet. Limited in what can be bound, and total number of shortcuts is hardcoded to 99.
Shortcuts can also be changed in about:addons -> gear -> Manage Extension Shortcuts.
Uses its own add-on ID (url-shortcuts-commands@local) and storage, so it can run alongside the Experiment API version.
Reserved Firefox shortcuts cannot be overridden, even obscure stuff like Alt+A and Alt+C that's not exposed by about:keyboard.
