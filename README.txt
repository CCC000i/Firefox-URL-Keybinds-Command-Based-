URL Shortcuts (Commands)

Up to 99 keyboard shortcuts that open configured URLs in a new tab, built on the standard WebExtension commands API (no Experiment API, AMO-signable).

Row N in the options page = command "URL Shortcut NN". Shortcuts can also be changed in about:addons -> gear -> Manage Extension Shortcuts.
Uses its own add-on ID (url-shortcuts-commands@local) and storage, so it runs alongside the Experiment API version.
Limits: reserved Firefox shortcuts cannot be overridden; about:, chrome: and javascript: URLs cannot be opened by extensions.
