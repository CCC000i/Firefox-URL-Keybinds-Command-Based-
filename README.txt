Mozilla-legal version of URL Keybinds (https://github.com/CCC000i/Firefox-URL-Keybinds), not signed yet. Native Firefox keybinds can't be overridden, and total number of shortcuts is hardcoded to 99. Lots of obscure stuff that's not even exposed by about:keyboard, like Alt+A and Alt+C, can't be bound.
Shortcuts can also be changed in about:addons -> gear -> Manage Extension Shortcuts.
Uses its own add-on ID (url-shortcuts-commands@local) and storage, so it can run alongside the Experiment API version.
