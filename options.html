PositionURLShortcutNotes
Modifiers: Ctrl / Alt / Shift (macOS: Ctrl = Command, MacCtrl = Control). Needs Ctrl or Alt; F-keys work alone.
Keys: A-Z, 0-9, F1-F12, Comma, Period, Home, End, PageUp, PageDown, Space, Insert, Delete, arrows.
Examples: Ctrl+Alt+K, Alt+Shift+1, F8. Up to 99 rows; row N = "URL Shortcut NN" in about:addons -> gear -> Manage Extension Shortcuts.
Reserved Firefox shortcuts cannot be overridden. about: URLs cannot be opened.
